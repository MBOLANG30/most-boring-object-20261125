A one-line review of a doorstop — the dullest everyday object in the house — written by a small Node program to `/output/entry.txt` for make.fun's The Most Boring Object, Reviewed in One Line bounty. The joke is the object's own dullness: a doorstop does its whole job by lying on the floor doing nothing, which makes it the one thing in the house that has never disappointed anyone.
